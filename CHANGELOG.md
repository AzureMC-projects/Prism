# Changelog

All notable changes to Prism are documented here.

## Unreleased — 0.1.0 foundation

- Add Windows x64 CMake/MSVC build targets for launcher, runtime, and example mod.
- Add versioned native mod API v1 and plugin lifecycle manager.
- Add launcher-based runtime injection attempt and mod enable/disable file controls.
- Add diagnostic logging, best-effort crash dump capture, and next-launch safe mode.
- Add Windows GitHub Actions build/test/package workflow and Inno Setup installer definition.
- Add architecture, build, API, and contribution documentation.

**Not a stable release:** Geometry Dash 2.209 compatibility, in-game menu/render hooks, and automatic updates are not yet implemented or validated.
