# Security Policy

## Scope

Prism is under active development. Please do not assume the loader or its native plugin API is a security boundary. A native mod DLL executes arbitrary code with the privileges of the game process.

## Reporting

Please report suspected vulnerabilities privately to the repository maintainers through GitHub's private vulnerability reporting feature if it is enabled. Avoid posting exploit details, crash dumps containing personal data, or account tokens in public issues.

## Safe use

- Install only mods from sources you trust.
- Keep backups of game saves.
- Treat API version checks as compatibility checks, not sandboxing.
- Crash dumps may contain process memory; inspect them before sharing.
