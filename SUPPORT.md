# Support

For bug reports, open a GitHub issue and include:

- Windows version and CPU architecture
- Prism commit or release tag
- Whether Geometry Dash was launched through Steam
- Reproduction steps and expected/actual behavior
- Relevant sanitized Prism log excerpts

Do not upload game executables, private account data, access tokens, or unreviewed crash dumps. Native mod loading is still under development; the launcher showing a successful DLL load does not confirm game compatibility.
